# Agent Instructions

These instructions apply to the O'Hara project.

Keep internal material private; exclude it with `.gitignore`.

## Naming

- Use `O'Hara` for the capitalized brand name, including document titles and prose.
- Use `ohara` for the lowercase name and project identifiers, including directory names and typed commands.

## Language Rules

- Use English for the default documentation file and Simplified Chinese for its `.zh.md` counterpart: `ideas.md` and `ideas.zh.md`.
- Keep both language versions equivalent in meaning and update them together.
- Write agent instruction files, including `AGENTS.md`, in English only; they are exempt from bilingual pairing.
- Use English for code identifiers, strings, and domain terms.
- Document language and commit-message language are separate conventions.

## Commit Messages

- Write commit messages in English.
- Do not include sensitive information in public files or commit messages.
